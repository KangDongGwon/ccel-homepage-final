# CCEL homepage — final drafts by Donggwon Kang (temporary preview)

Three design themes (Awesomic, Intercom, Mercury) over one shared function layer:

- Data and inner pages (`_shared/content.js`, professor / members / research / publications / contact):
  Jinuk Moon's [ccel-s1](https://github.com/jinukmoon/ccel-s1), used unchanged.
- Home page layout: after Kiheon Sung's draft C.
- Themes, scroll motion and the CSS bridge (`src/`): this repository.

Static site, no build step needed to view. `build_final.py` regenerates it from local sources.
Preview only (noindex); this repository will be deleted after a design is chosen.
